# mission_christ

선교사와 후원자를 잇는 **비공개 커뮤니티 앱**.

기도제목을 올리고, 사역 소식과 간증을 나누고, 후원 계좌를 안내하고, 귀국했을 때 머물 숙소를 찾을 수 있다. 지금 네이버 밴드·카페·단톡방에 흩어져 있는 일들을 한곳에서, 그리고 **훨씬 안전하게** 한다.

> **앱은 스토어에 공개되지만, 앱 안에 기록되는 모든 자료는 비공개다.**
> 이것이 이 프로젝트의 설계 원칙이다.

## 왜 만드는가

- **프라이버시**: 밴드·카페는 검색에 노출되거나 초대만 받으면 열린다. 사역지 사진 한 장, 지역명 한 줄이 선교사와 현지 사역자에게 위험이 될 수 있다.
- **흩어진 소식**: 기도제목은 밴드에, 후원 계좌는 카톡에, 사진은 또 다른 곳에 있다. 후원자는 한곳에서 볼 수 없다.
- **귀국 숙소**: 안식년·보고 방문으로 들어와도 머물 곳이 없다. 저렴하게 또는 무료로 방을 내어주려는 사람은 있는데, 서로를 찾을 방법이 인맥밖에 없다.

## 주요 기능 (MVP)

| | |
|---|---|
| **피드** | 기도제목 · 간증 · 나눔 · 사진. 글마다 공개 범위 선택 (기본값: 내 후원자만) |
| **기도 반응** | "기도했어요" · 댓글. 응답받은 기도제목은 '응답'으로 전환 |
| **후원** | 선교사가 계좌·QR 등록 → 후원자가 확인하고 직접 송금. **앱 내 결제는 하지 않는다** |
| **숙소** | 호스트가 방을 등록하고 선교사가 요청. 전체 공개 또는 **특정 선교사 지정**. 상세 주소는 수락 후에만 공개 |
| **인증** | 선교사는 관리자 승인 후 뱃지. 인증 전에는 읽기만 가능 |

## 대상

필리핀·일본·동남아·국내 등 **SNS 사용이 가능한 지역**의 선교사와 그 후원자, 그리고 숙소를 내어줄 수 있는 호스트.
보안 통제가 극심해 일반 SNS 자체를 쓸 수 없는 지역은 이번 범위가 아니다. 다만 가명·지역 비공개 옵션은 처음부터 제공한다.

## 기술 스택

- **앱** — React Native + Expo (TypeScript), Expo Router
- **백엔드** — Supabase (Postgres · Auth · Storage). 전 테이블 Row Level Security 기본 차단
- **이미지** — 비공개 버킷 + 단기 만료 서명 URL
- **푸시** — Expo Notifications
- **데이터** — TanStack Query + Zustand
- **배포** — EAS Build / EAS Update

웹 버전은 만들지 않는다. 크롤링 대상을 만들지 않기 위해서다.
